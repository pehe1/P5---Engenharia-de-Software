# P5 — Engenharia de Software

Repositório de um dos módulos do projeto P5.

## Estado atual

O código versionado contém apenas `hello-world.py`, um exemplo inicial. A
responsabilidade do microsserviço e sua interface com os demais módulos ainda
precisam ser definidas pelo grupo; este repositório não expõe uma API.

Para executar o exemplo, use Python 3:

```bash
python3 hello-world.py
```

A saída esperada é `Hello World!`.

## Colaboração

Cada integrante pode registrar sua contribuição em uma branch própria:

1. Criar uma branch a partir de `main`.
2. Fazer uma alteração identificável e um commit com seu próprio usuário.
3. Abrir um pull request para `main`, descrevendo a mudança e como verificá-la.
4. Revisar e concluir o merge no GitHub.

Antes de implementar o microsserviço, o grupo deve registrar aqui sua
responsabilidade, as entradas e saídas esperadas e como executá-lo e testá-lo.
